# walletkit

A React wallet kit for Web3 integrations — lightweight adapters, hooks and UI components.

## Installation

- Build the library:

```bash
npm install
npm run build
```

- In your app, import from the built package (`lib`) or use the `src` files in development.

## Features

- Wallet adapters (MetaMask, WalletConnect)
- `WalletProvider` and `useWallet()` hook
- UI components: `ConnectButton`, `AccountInfo`

## Development

Run `npm run dev` to build in watch mode.

## Demo

Run the demo locally with Vite:

```bash
npm install
npm run demo
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).
